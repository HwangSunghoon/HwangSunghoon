# 황성훈

경희대학교 소프트웨어융합학과에서 데이터사이언스와 인공지능을 공부하고 있습니다.

데이터를 수집하고 분석하는 과정부터 모델링, 애플리케이션 구현까지 직접 연결하는 프로젝트에 관심이 있습니다. 분석 결과를 설명하는 데 그치지 않고, 실제 사용자가 활용할 수 있는 서비스와 도구로 구현하는 것을 목표로 합니다.

## 관심 분야

- 데이터 분석 및 통계적 모델링
- 머신러닝과 딥러닝
- Multi agent, LLM Agent 및 RAG
- 데이터 기반 서비스 개발
- 백엔드 시스템과 iOS 애플리케이션

## 주요 프로젝트

### [인증시세 렌즈](https://github.com/HwangSunghoon/certified-price-lens)

중고차 데이터의 회귀분석과 군집분석 결과를 실제 구매 판단에 활용할 수 있도록 구현한 Chrome 확장 프로그램입니다.

- 차급별 가격 회귀모형 설계
- K-Means 기반 인증중고차 프리미엄 분석
- 분석 결과를 브라우저 확장 프로그램으로 구현
- Python, Pandas, scikit-learn, JavaScript

### [Shopping AI Agent](https://github.com/HwangSunghoon/shopping-ai-agent)

자연어로 입력된 쇼핑 조건을 해석하고 상품을 검색·추천·재정렬하는 AI 검색 서비스입니다.

- LLM과 규칙 기반 로직을 활용한 검색 조건 추출
- 사용자 선호와 대화 문맥을 반영한 상품 재정렬
- Next.js 프론트엔드와 FastAPI 백엔드 구성
- Python, FastAPI, Next.js, TypeScript, SQLAlchemy

### [Mafia Night](https://github.com/HwangSunghoon/agent-mafia-night)

독립된 기억과 판단 상태를 가진 AI 참가자들이 사용자와 실시간으로 게임을 진행하는 멀티 에이전트 시스템입니다.

- 참가자별 관점과 기억이 분리된 Agent 구조
- WebSocket 기반 실시간 게임 진행
- PostgreSQL과 Redis를 활용한 상태 관리
- Python, FastAPI, WebSocket, PostgreSQL, Redis

### [SilentCop](https://github.com/HwangSunghoon/SilentCop)

공공데이터와 실시간 위치 정보를 활용해 전방 과속 단속카메라를 안내하는 iOS 애플리케이션입니다.

- GPS 위치와 진행 방향을 활용한 카메라 탐지
- MapKit 기반 지도 및 SwiftUI 인터페이스
- 백그라운드 위치 업데이트와 음성 안내
- Swift, SwiftUI, MapKit, Core Location

### [중고차 가격 형성 요인 분석](https://github.com/HwangSunghoon/used-car-price-analysis)

국내 중고차 매물 데이터를 수집하고 가격 형성 요인을 통계적으로 분석한 데이터사이언스 프로젝트입니다.

- 데이터 수집과 전처리
- 회귀분석과 상호작용항 분석
- ANOVA F-test와 군집분석
- Python, Pandas, SciPy, scikit-learn, Jupyter

### [Smart Factory Edge AI](https://github.com/HwangSunghoon/Smart-Factory-Edge-AI)

제한된 CPU 환경에서 철강 표면 결함을 분류하기 위해 모델을 비교하고 최적화한 컴퓨터 비전 프로젝트입니다.

- 철강 표면 결함 이미지 분류
- 제한된 연산 환경을 고려한 모델 최적화
- Python, PyTorch, Computer Vision
